# Netflix Data Analysis

##  Project Overview
This project performs exploratory data analysis on the Netflix dataset to identify trends and patterns in movies and TV shows available on the platform.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Analysis of movies vs. TV shows
- Content trends over time
- Country-wise content analysis
- Genre analysis
- Data visualization

##  Objective
The objective of this project is to analyze Netflix content and extract meaningful insights from the dataset using Python and data visualization techniques.

##  Project File
- Netflix-2.ipynb — Complete Jupyter Notebook containing the analysis, visualizations, and findings.

##  Key Skills Demonstrated
Python | Data Cleaning | EDA | Data Visualization | Pandas | NumPy | Matplotlib | Seaborn
